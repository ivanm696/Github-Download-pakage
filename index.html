Минимум настройки — максимум автоматизации. Нулевые внешние зависимости.

CI · passing tests · 10/10 node · ≥16 MIT license npm · @ivanm696
BUILD
Автосборка
Каждый push запускает сборку: транспиляция, линтинг, минификация. Результат в dist/.
TEST
Тесты на Node assert
10 тестов без единой зависимости. Матрица Node 18 / 20 / 22 на ubuntu-latest.
DEPLOY
Деплой в 1 клик
Workflow deploy.yml умеет staging и production. Выбор среды через inputs.
PUBLISH
GitHub Packages
При создании Release пакет автоматически публикуется в npm.pkg.github.com.
API
Простой API
robot.start() · robot.process() · robot.status() — три метода для управления всем.
ZERO
Zero deps
Только встроенные модули Node.js. Никаких уязвимостей в зависимостях.

Начать за 30 секунд

Клонируй, установи, запусти.

BASH · клонирование
$ git clone https://github.com/ivanm696/Github-Download-pakage.git
$ cd Github-Download-pakage
$ npm install
JAVASCRIPT · использование
const robot = require('@ivanm696/robot-package');
robot.start();

robot.process('build', { target: 'production' })
  .then(() => console.log('✅ готово'));
BASH · запуск тестов
$ npm test
  ✔ robot.start() возвращает статус running
  ✔ robot.process("build") завершается успешно
  ...
  📊 Результат: 10 пройдено, 0 провалено
